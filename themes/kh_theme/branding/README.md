# Branding Knowledge Hub

| File | Dipakai untuk |
|---|---|
| `logo-mark.svg` | Simbol utama (gradient indigo ke violet) |
| `logo-mark-white.svg` | Simbol di latar gelap |
| `logo-mark-mono.svg` | Satu warna: cetak, stempel, fax |
| `logo-horizontal.svg` / `.png` | Simbol + wordmark. Teks memakai Inter; ubah ke outline sebelum dikirim ke percetakan |
| `logo-horizontal-white.svg` | Wordmark untuk latar gelap |
| `favicon.svg`, `favicon-32.png`, `favicon-192.png` | Ikon tab dan PWA. Glyph lebih tebal agar terbaca di 16px |
| `apple-touch-icon.png` | Ikon layar utama iOS (180x180) |
| `og-image.svg` / `.png` | Pratinjau tautan (1200x630) |

Aturan: ruang kosong di sekeliling simbol minimal setinggi huruf K, simbol minimal 24px, jangan diputar atau diberi efek.
Favicon dan OG dipasang oleh `kh_theme_page_attachments_alter()` di `kh_theme.theme`.
